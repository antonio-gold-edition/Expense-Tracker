# Expense Tracker with Visuals

A Streamlit app to track expenses and visualize spending.

## Features
- Add expenses via form or CSV upload
- Group spending by category and date
- Pie, bar, and line charts
- Monthly budget alerts (warning at 80%, error at 100%)
- Export report to Excel

## Run
pip install -r requirements.txt
streamlit run app.py

## CSV format
date,category,amount,note
